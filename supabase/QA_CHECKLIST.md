# قائمة اختبار شاملة (QA Checklist)

هذه القائمة تغطي دورة العمل الكاملة والحالات الحدّية المطلوبة في مرحلة
الاختبار النهائي. نفّذها بعد ربط مشروع Supabase حقيقي (`supabase/README.md`)
— لا يمكن تنفيذها آليًا من طرفي بدون بيانات اعتماد مشروع فعلي.

## دورة العمل الكاملة
- [ ] تسجيل دخول admin من `/admin/login`
- [ ] الوصول إلى `/admin` ومشاهدة إحصائيات حقيقية (لا أصفار وهمية إن كانت هناك بيانات)
- [ ] إضافة عقار جديد من `/admin/properties/new` بكل الحقول
- [ ] رفع عدة صور للعقار من صفحة التعديل
- [ ] تحديد صورة رئيسية مختلفة عن أول صورة مرفوعة
- [ ] إعادة ترتيب الصور بالسحب والإفلات، والتأكد من بقاء الترتيب بعد تحديث الصفحة
- [ ] إدخال Latitude/Longitude واختيار المميزات
- [ ] حفظ العقار كمسودة (published = false) والتأكد من عدم ظهوره في `/properties`
- [ ] نشر العقار (published = true) والتأكد من ظهوره فورًا في الرئيسية والقائمة
- [ ] البحث عن العقار من `/properties` بالاسم/الفلاتر
- [ ] تصفية النتائج (مدينة، غرض، نوع، سعر، غرف) والتأكد من صحة النتائج
- [ ] التبديل لعرض الخريطة ومشاهدة Marker للعقار الجديد ضمن Cluster عند التقارب
- [ ] فتح صفحة تفاصيل العقار والتأكد من كل البيانات (صور، سعر، مميزات، خريطة الموقع)
- [ ] الضغط على زر واتساب والتأكد من فتح محادثة برقم صحيح ورسالة تحتوي رقم العقار
- [ ] إرسال نموذج "طلب معاينة" من صفحة التفاصيل
- [ ] التأكد من وصول الطلب إلى `/admin/leads` بكل بياناته والعقار المرتبط
- [ ] تغيير حالة الطلب إلى "تم التواصل" ثم "إغلاق" من لوحة التحكم
- [ ] حذف العقار نهائيًا والتأكد من اختفائه من كل الصفحات العامة والخريطة والـSitemap

## حالات حدّية
- [ ] فتح رابط عقار غير موجود (`/properties/does-not-exist`) → صفحة "غير موجود" مخصصة
- [ ] فتح رابط عقار مسودة (published = false) من الموقع العام → نفس صفحة "غير موجود" (لا تسريب بيانات)
- [ ] تصفية تُرجع صفرًا من النتائج → حالة "لا توجد نتائج" مع زر مسح الفلاتر
- [ ] رابط صورة تالف/محذوف يدويًا من Storage → يظهر Placeholder بدل كسر التصميم (`ImageWithFallback`)
- [ ] محاولة رفع ملف `.pdf` أو ملف أكبر من 5 ميجابايت → رسالة رفض واضحة، لا يُحفظ شيء
- [ ] فتح `/admin` مباشرة في تبويب متصفح بدون تسجيل دخول → Redirect فوري لـ`/admin/login`
- [ ] حذف كوكيز الجلسة يدويًا أثناء تصفح لوحة التحكم ثم تحديث الصفحة → Redirect لتسجيل الدخول (Session منتهية)
- [ ] تسجيل الدخول بحساب Auth صحيح لكن بدون صف `admin` في `profiles` → رفض فوري برسالة واضحة
- [ ] ترك حقل مطلوب فارغًا في نموذج العقار (مثل السعر أو العنوان) → رسالة تحقق تحت الحقل تحديدًا، لا حفظ جزئي
- [ ] محاولة حذف مدينة/حي/نوع مرتبط بعقار موجود → رفض مع رسالة عربية واضحة (وليس خطأ خادم عام)
- [ ] معاينة الموقع العام ولوحة التحكم على الجوال والتابلت وسطح المكتب
- [ ] التأكد أن كل الصفحات (عامة وإدارية) تحافظ على اتجاه RTL بلا انكسار تخطيط

## بعد الاختبار
- [ ] `npm run build` بدون أخطاء
- [ ] `npx eslint .` بدون أخطاء (تحذير الخطوط المعروف مقبول)
- [ ] `/sitemap.xml` يحتوي فقط على العقارات المنشورة فعليًا
- [ ] `/robots.txt` يمنع فهرسة `/admin`
